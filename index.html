Power Converter Test Bench

Independent project · Nov 2025 – Jan 2026
STM32Embedded C / HALIsolated sensingAnalog filtersPython GUI

A test bench for evaluating two DC-DC converters ORed together for redundancy. It combines analog front-end design, galvanic isolation, embedded firmware and PC software in one system, so converters can be failed over and measured safely and repeatably.

Analog sensing and isolation

  • Input and output voltage/current sensing, each path with its own gain stage and 2nd-order filter.
  • Galvanically isolated sensing amplifiers keep the control side separate from the high-power converter side.
  • Gain stage designed as a configurable differential-to-single-ended amplifier for unipolar or bipolar measurements.
  • Converter enable signals pass through optocoupler-isolated logic so a glitch cannot switch on a converter carrying real power.

Firmware and host software

  • STM32F302R8T6 firmware (HAL) reads the ADC via DMA, leaving CPU headroom for USB traffic.
  • USB CDC link to the PC with a custom structured packet format; GPIO enables each converter on host command.
  • Python parser, command-line interface and a real-time monitoring GUI for long test sessions.

Key decisions

  • Optocoupler isolation on the enable path was a safety choice, not just a functional one.
  • DMA acquisition instead of polling, anticipating continuous multi-channel throughput.
  • Built both a CLI and a GUI because the bench would be used through many test iterations.

Design challenge: op-amp oscillation near 2.5 V

Failure analysis
Symptom

ADC readings were stable at low signal levels but began oscillating as the signal approached about 2.5 V, then settled again once it dropped back. The behaviour was consistent and repeatable, which pointed to a signal-integrity problem rather than random noise.

Diagnosis
  1. Probed the gain stage and filter stage separately. The gain stage was stable over the full 0–3.3 V range, which isolated the problem to the filter.
  2. Swept the ADC sampling rate. Oscillation started at the same voltage every time, ruling out sample-and-hold charge time.
  3. Removed the filter op-amp and fed the sensor straight into the ADC. The oscillation disappeared, confirming the op-amp in its feedback configuration as the cause.
Root cause and fix

The original op-amp was not unity-gain stable in the filter's configuration. Swapping it for a unity-gain-stable part fixed the issue completely; readings stayed stable from 0 to 3.3 V.

ADA4891 → TLV9054
Takeaway

Check an op-amp's stability against its actual closed-loop configuration, not just its gain-bandwidth and offset specs. Filter feedback networks can affect stability differently than a simple gain stage.

3.75 kW Active Full-Bridge Rectifier

Power electronics research, University of Calgary · May – Sept 2025
Altium DesignerHigh-voltage layoutGalvanic isolationTest fixture

PCB design for a 3.75 kW active full-bridge rectifier rated for 400 V, built for undergraduate power electronics research. The board had to switch high voltage safely while protecting operators and downstream circuitry.

Isolation strategy

Isolated voltage and current sensors plus isolated gate drivers separate the high-voltage power stage from the low-voltage control and measurement circuitry.

Test fixture and integration

I also specified and built the test setup: chose screws and ring terminals to match the board's power connections, crimped the terminals, and integrated a 6 kW power supply to source the rectifier under test.

Key decisions

  • Creepage and clearance were set at the layout stage, not checked afterward, given the consequences of getting high-voltage spacing wrong.
  • Isolated sensing and gate drive were chosen specifically to protect people and instruments from the 400 V stage.

600 W DC-DC Converter

Independent project · Sept – Nov 2025
Power sequencingThermal validationPCB design

A 600 W, 143 V-to-12 V converter built around the Cincon CFB600W module, designed as one half of the redundant pair used on the test bench above.

Power sequencing and fault prevention

Dedicated sequencing logic lets the converter enable only after auxiliary power is confirmed present. This stops it from starting into an undefined or partially powered state, removing a class of startup faults that appear when control and gate-drive rails aren't yet stable.

Key decisions

  • Treated startup sequencing as a design requirement instead of assuming auxiliary power would always arrive first, a failure mode that tends to surface as an intermittent fault.
  • Validated with a 30-minute continuous run at 25 A instead of a brief functional check, to build confidence in real thermal performance.
